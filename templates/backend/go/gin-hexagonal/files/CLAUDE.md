# CLAUDE.md — generated Go API

Read [AGENTS.md](AGENTS.md) and [CONTEXT.md](CONTEXT.md) first. CONTEXT.md is
the source of truth for architecture, security, and the quality gate.

This is a hexagonal Go HTTP API generated by smokeforge.

## Essentials

- **Stack:** Go 1.26, Gin, spec-first OpenAPI (`oapi-codegen`), Zap,
  `caarlos0/env`, validator, RFC 9457 errors, `x/time/rate`.
- **Architecture:** `cmd/api` → `internal/httpapi` → `internal/app` → `internal/port` → `internal/service` → `internal/domain`. Feature packages register through `httpapi.Registrar`.
- **Docs:** Swagger UI at `/docs`; merged contract at `/openapi.json`.
- **Database:** optional pgx + sqlc + goose overlay.
- **Auth:** optional HS256 JWT + rotating refresh + TOTP overlay.
- **Skills:** use `.agents/skills` and `.claude/skills`; see CONTEXT.md.

## Non-negotiables

- Contract first: edit OpenAPI, regenerate, then implement.
- TDD: failing test before implementation.
- Validate at the boundary; trust internal code.
- Errors are RFC 9457 error responses; log details server-side only.
- Never commit secrets or expose tokens/passwords in logs.
- Never build SQL with string concatenation.
- Keep pprof on the separate opt-in listener.
- Run `make ci` before claiming completion.
