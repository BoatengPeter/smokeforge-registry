# Design System: Desktop GPUI

Use GPUI Kit semantic theme tokens (`cx.theme()`), the component library, and the GPUI Kit design guides. Dark is the default; light and high contrast are supported.

- Fixed sidebar, title bar, workspace, and status bar.
- Dense desktop spacing, 32–36px controls.
- One primary action per group.
- Tables and lists use GPUI Kit virtualized components.
- Overlays use GPUI Kit Dialog/Sheet/Notification with Escape dismissal and focus return.
- No raw hex colors in feature views.
